# Smart-Resume-builder
A Smart Resume Builder web application that allows users to create professional, ATS-friendly resumes with a live A4 preview. Features include 3 unique resume templates, drag-and-drop section reordering, PDF export, and local data storage with file import/export for easy access and editing.
📝 Easy-to-use resume creation form.
📄 Real-time A4 resume preview.
🎨 3 visually distinct professional templates.
↕️ Drag-and-drop resume section reordering.
📥 Export resumes as PDF.
💾 Save personal data locally on the device.
📂 Export and import resume data as a file.
🔒 No account required; data stays on the user's device.
